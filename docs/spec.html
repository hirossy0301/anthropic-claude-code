仕様書

競艇統計予想アプリ

branch: claude/cloud-session-credit-verify-mh18aa · Python 3.11 / SQLite / LightGBM / Streamlit

1概要

ボートレース公式の過去データ（番組表・競走成績）を集計します。そのデータから、各艇の1着確率と3連単120通りの確率を推定するアプリです。

データ元：ボートレース公式 ダウンロードページ

  1. 取得LZH を日付ごとに取得download.py
  2. 解析固定長テキストを読むparsers.py
  3. 保存SQLite の3テーブルdb.py
  4. 特徴量前日までの情報のみfeatures.py
  5. 1着確率分類モデル＋正規化model.py
  6. 3連単Plackett-Lucemodel.py
  7. 表示画面・CLIapp.py / cli.py
未検証の点：開発環境から公式サイトに接続できませんでした。そのため、パーサーは公開されているファイル形式の知識をもとに作っており、実ファイルではまだ動作を確かめていません。初回の取り込み後に件数を確認してください（1日あたり 出走数 ≈ レース数 × 6）。

画面（Streamlit）

  • 日付・場・レースを選ぶと、各艇の1着確率（表と棒グラフ）と3連単の上位が表示されます。
  • 結果が確定しているレースでは、実際の3連単・払戻金と「予想の何位だったか」も表示されます。
  • スマホで見る場合は streamlit run app.py --server.address 0.0.0.0 で起動します。同じWi‑Fiにつないだスマホのブラウザで http://<PCのIPアドレス>:8501 を開いてください。

場コード（--venue）は公式の番号に従います。例：01 桐生、02 戸田、12 住之江、24 大村。

3データ

公式ファイルは Shift_JIS の固定長テキストで、全角数字と全角空白が混ざっています。そこで行ごとに NFKC 正規化（全角英数字を半角に揃える処理）をかけます。そのうえで、桁位置ではなく正規表現で項目を読み取ります。全角と半角が混ざると桁位置がずれやすいためです。

テーブル元ファイル主な列キー
entries番組表 (B)枠、登録番号、選手名、年齢、支部、体重、級別、全国・当地の勝率と2連率、モーター番号と2連率、ボート番号と2連率日付・場・R・枠
results競走成績 (K)着順（F・L・K・S などの失格・欠場は NULL）、展示タイム、進入コース、スタートタイミング、フライングの有無日付・場・R・枠
races競走成績 (K)3連単の組番・払戻、単勝払戻、風向、風速、波高日付・場・R

リーク防止とベイズ平滑化

履歴系の特徴量は、予想する日の前日までのデータだけで計算します。当日以降の結果を混ぜると未来の情報が入り込み、バックテストの成績が実力以上に良く見えてしまうためです。同じ日の先に終わったレースの結果も使いません。朝の時点で1日分を予想する使い方を前提にしているためです。

出走数が少ない選手は率が極端な値になりやすいので、事前の値（prior）を k 件分足して平均をならします。

平滑化した率 = (前日までの合計 + prior × k) ÷ (前日までの件数 + k)

racer_avg_st0.165平均的なスタートタイミング
racer_lane_win1/656艇立ての均等確率
racer_win1/610同上
venue_lane_win1/650場×枠は件数が多いので強めにならす

51着確率モデル

各艇について「1着になるか」を二値分類で学習します。その出力 si を、レース内で合計が1になるよう正規化します。

pi = si ÷ (s1 + s2 + … + s6)
モデル役割設定
LightGBM本番用木 400本、学習率 0.03、葉数 31、葉の最小件数 50、行・列のサンプリング 0.8
ロジスティック回帰比較用標準化したうえで学習。欠損は学習データの中央値で補完
場×枠の1着率ベースライン学習期間の「場ごとの枠別1着率」をそのまま確率にする

学習に使うのは、結果が確定していて、6艇がそろい、1着が1艇だけのレースです。欠場や全艇フライングなどのレースは除きます。

63連単確率

1着確率から、3連単120通りの確率を Plackett-Luce（Harville）モデルで計算します。これは「1着を決めたら残りの艇の中から次の着を決める」という順番で確率を掛け合わせる方法です。

P(a-b-c) = pa × pb ÷ (1 − pa) × pc ÷ (1 − pa − pb)

P(1-2-3) = 0.50 × 0.20 ÷ 0.50 × 0.10 ÷ 0.30 = 0.50 × 0.40 × 0.333 ≈ 0.067（6.7%）

120通りの確率を合計すると1になります（テストで確認済み）。

7評価方法

時系列分割で評価します。--cutoff より前の期間で学習し、それ以降の期間で検証します。ランダムに分割すると、未来のレースで学習してしまうため使いません。

指標定義良い方向
1着的中率1着確率が最も高い艇が実際に1着だった割合高い
対数損失実際の1着艇に付けた確率 p の −log(p) の平均低い
3連単 上位N点の的中率確率の上位N点の中に、実際の3連単が入っていた割合高い
回収率払戻の合計 ÷（N点 × 100円 × レース数）100% を超えれば収支がプラス

8制約と注意

  • パーサーは実ファイルで未検証です。初回の取り込み後に件数と値を確認してください。
  • オッズを使っていません。競走成績に入っているのは確定後の払戻だけなので、期待値がプラスの買い目を判定できません。回収率100%超えを狙うには、直前オッズの取得が必要です（利用規約の確認が前提です）。
  • Harville モデルには偏りがあります。2着・3着の確率に偏りが出やすいことが知られています。改善するなら、2着・3着を別のモデルで補正する方法があります。
  • 直前情報を使っていません。展示タイム・進入コース・気象は結果ファイルにはありますが、予想時点では使っていません。当日の直前情報を取得すれば追加できます。
  • 当日の予想には、当日分の番組表の取り込みが必要です。毎日の自動化（定期実行）はまだ実装していません。
  • 3年分の取得には、1.5秒間隔で約2,200リクエスト、約1時間かかります。
確率は過去データからの統計的な推定です。的中や利益を保証するものではありません。
